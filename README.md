# SAHAJ SETU 🚀
### AI-Assisted Platform for Industrial Approvals and Compliance

**SAHAJ SETU** is a digital platform designed to simplify industrial approval processes and compliance workflows for entrepreneurs. It aims to provide a unified experience for applicants and government officers through organized application management and AI-assisted insights.

## 📌 About the Project

Navigating industrial approvals and compliance requirements can be complex and time-consuming for entrepreneurs.

SAHAJ SETU aims to simplify this journey by bringing applicant services, approval workflows, and officer-side operations into one platform.

The project was developed as part of a collaborative hackathon initiative addressing industrial approval and compliance challenges.

## 🎯 Problem Statement

Entrepreneurs may face difficulties understanding approval requirements, tracking application progress, and navigating multiple compliance procedures.

SAHAJ SETU focuses on improving accessibility, transparency, and workflow management through a unified digital solution.

## ✨ Key Features

- **Unified Platform:** Applicant-side and officer-side interfaces.
- **Application Management:** Organized industrial approval workflows.
- **Compliance Support:** Designed to guide entrepreneurs through approval-related requirements.
- **AI-Assisted Insights:** Planned support for risk scoring and approval-delay prediction, depending on the implemented functionality.
- **Dashboard:** Provides an interface for monitoring approval-related information.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/sahaj-setu-project.git
cd sahaj-setu-project
```

### 2. Install backend dependencies

```bash
cd sahaj-setu-backend
npm install
```

### 3. Configure environment variables

Create a local `.env` file in the backend directory and configure the required values, such as the MongoDB connection string and application port.

**Never commit `.env` files, passwords, API keys, or database credentials.**

### 4. Start the backend

Check `package.json` for the available scripts. If the project uses a `dev` script, run:

```bash
npm run dev
```

### 5. Run the frontend

Open the frontend using the method supported by the project configuration.
